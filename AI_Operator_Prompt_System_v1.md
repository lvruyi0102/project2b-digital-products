### How to Use This System

1. Copy a prompt into Claude, ChatGPT, Grok, or your preferred AI tool.
2. Replace the bracketed placeholders with your specific details.
3. Iterate 1-2 times for higher quality.
4. Save the best outputs as templates for reuse.
5. Combine prompts for multi-step workflows.

**Pro Tip:** The highest ROI prompts are those that directly produce something you can sell, send to a client, or use for marketing today.

## Category 1: Client Acquisition & Outreach (25 Prompts)

### 1. Personalized Cold Outreach Email Generator
```
Act as a world-class sales copywriter who specializes in high-converting B2B outreach for [your service type].

Write a short, personalized cold email to [prospect role] at [company type] who is likely struggling with [specific pain point].

Structure:
- Subject line (under 50 characters, curiosity-driven)
- Opening line that references something specific about their business or industry
- One clear pain point + consequence
- Brief credibility or result (without sounding salesy)
- Soft CTA for a 15-minute call or reply

Tone: Confident, helpful, not pushy. Length: 90-130 words.
```

### 2. LinkedIn Connection Request Message
```
Write a LinkedIn connection request message (under 300 characters) to a [target role] who posted about [topic]. Reference their post naturally and offer a specific, small value without asking for anything.
```

### 3. Discovery Call Script Outline
```
Create a 15-minute discovery call script for selling [your service]. Include:
- Opening rapport question
- 4 diagnostic questions that uncover pain and budget
- How to transition to presenting a solution
- Handling the "I need to think about it" objection
```

### 4. Proposal Template Generator
```
Generate a professional proposal structure for a [service type] project worth [price range]. Include sections: Executive Summary, Scope of Work, Timeline, Investment, Next Steps. Make the language client-focused and outcome-oriented.
```

### 5. Follow-Up Sequence (3 emails)
```
Write a 3-email follow-up sequence for prospects who went quiet after an initial conversation about [service]. Email 1: value-add, Email 2: social proof, Email 3: scarcity/soft close. Keep each under 100 words.
```

## Category 2: Content Creation & Marketing (30 Prompts)

### 1. High-Performing X/Twitter Thread
```
Write a 7-tweet thread about [topic related to your expertise] that ends with a soft CTA to [your offer or free resource]. Start with a strong hook. Use short sentences. Include one specific example or number in each tweet.
```

### 2. LinkedIn Post That Gets Engagement
```
Write a LinkedIn post (150-250 words) about a lesson I learned from [experience]. Structure: Hook → Story → Lesson → Question to drive comments. Tone: authentic and professional.
```

### 3. YouTube Video Script Outline
```
Create a detailed outline for a 8-12 minute YouTube video titled "[title]". Include hook (first 30 seconds), 3 main points with examples, and a clear CTA at the end.
```

### 4. Newsletter Edition
```
Write a complete weekly newsletter edition on [topic]. Include: subject line options (3), opening hook, one main insight with practical steps, and a soft CTA.
```

### 5. Product Description for Digital Product
```
Write a high-converting product description for [digital product]. Include: headline, problem statement, what the buyer gets, 5-7 benefit bullets, who it's for, and a strong close.
```

## Category 3: Digital Product Creation & Sales (25 Prompts)

### 1. Digital Product Idea Validator
```
I want to create a digital product for [audience] that solves [problem]. Generate 5 specific product ideas ranked by estimated demand, competition, and ease of creation. For the top idea, outline the table of contents and suggested price.
```

### 2. Sales Page Outline
```
Create a complete sales page outline for [product name]. Sections: Headline, Subheadline, Problem Agitation, Solution Introduction, What's Included, Testimonials placeholders, FAQ, Guarantee, CTA.
```

### 3. Launch Email Sequence (5 emails)
```
Write a 5-email launch sequence for [product]. Email 1: announcement, Email 2: problem deep-dive, Email 3: solution preview, Email 4: social proof, Email 5: last chance.
```

### 4. Customer Onboarding Email
```
Write a warm, helpful onboarding email for buyers of [product]. Include: what to do first, where to find support, and one quick win they can achieve in the next 24 hours.
```

## Category 4: Operations, Systems & Productivity (20 Prompts)

### 1. Standard Operating Procedure (SOP) Generator
```
Create a clear, step-by-step SOP for [process, e.g., client onboarding or content publishing]. Format it so a VA or new team member can follow it without asking questions.
```

```
Based on my current goals [list goals] and constraints [list constraints], create a realistic weekly plan with the 3 highest-leverage activities and a suggested daily schedule.
```

```
Generate a structured meeting agenda and note-taking template for a [type of meeting] that keeps the discussion focused and produces clear action items.
```

## Category 5: Advanced / High-Leverage Workflows (20 Prompts)

### 1. Multi-Step Content Repurposing System
```
I have this long-form content: [paste or describe]. Turn it into:
1. A LinkedIn post
2. A 7-tweet thread
3. A short email newsletter
4. 5 short-form video scripts
Keep the core message consistent while adapting the format.
```

### 2. Competitor Analysis Prompt
```
Analyze the positioning of [competitor 1], [competitor 2], and [competitor 3] in the [market] space. Identify gaps and opportunities for differentiation for a solopreneur offering [your offer].
```

### 3. Pricing Strategy Advisor
```
Given that I sell [product/service] to [audience], suggest 3 pricing models with pros/cons and a recommended starting price based on current market conditions in 2026.
```
